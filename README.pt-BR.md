# mips-assembly-ac1

Programas em assembly MIPS da disciplina de Arquitetura de Computadores I (IFSul, Ciência da Computação),
atividade AT01, grupo 09. Faz parte do meu repositório de [estudos](https://github.com/pedrohrossetto/studies).

Autores: Pedro Henrique Carteli Rossetto e Matheus Pastore Polese.

## Conteúdo

| Caminho | Descrição |
|---|---|
| `ifsul_arq1_at-01_grupo-09/q-01.asm` … `q-04.asm` | Soluções das quatro questões: registradores, acesso à memória, aritmética, desvios e laços |
| `docs/valores-grupo-09.txt` | Valores de entrada atribuídos ao grupo |
| `tests/hello-world.asm` | Teste x86-64 (NASM) do ambiente MSYS2 |

## Como rodar

Abra os `.asm` no simulador [MARS](https://dpetersanderson.github.io/) (Java), monte (F3) e execute (F5).
