# mips-assembly-ac1

MIPS assembly programs for the Computer Architecture I course (IFSul, Computer Science),
assignment AT01, group 09. Part of my [studies](https://github.com/pedrohrossetto/studies) archive.

Authors: Pedro Henrique Carteli Rossetto and Matheus Pastore Polese.

## Contents

| Path | Description |
|---|---|
| `ifsul_arq1_at-01_grupo-09/q-01.asm` … `q-04.asm` | Solutions to the four questions: registers, memory access, arithmetic, branches and loops |
| `docs/valores-grupo-09.txt` | Input values assigned to the group |
| `tests/hello-world.asm` | x86-64 NASM sanity check for the MSYS2 toolchain |

## Running

Open the `.asm` files in the [MARS MIPS simulator](https://dpetersanderson.github.io/) (Java),
assemble (F3) and run (F5).
